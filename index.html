01. Tentang Saya

Saya backend developer asal Bali yang senang membangun sistem yang andal — dan memastikan sistem itu aman. Saya membuat project personal seperti CDN simulator (edge caching, multi-region routing, observability) sambil mendalami keamanan aplikasi web.

Baru saja saya mengaudit project sendiri dengan pendekatan OWASP: menemukan 11 celah (4 di antaranya high severity — admin API tanpa autentikasi, SSRF, Redis & Grafana terbuka), lalu memperbaiki semuanya lengkap dengan regression test yang berjalan otomatis di CI.
